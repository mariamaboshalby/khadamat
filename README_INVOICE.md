# 🧾 نظام الفواتير - منصة خدمات

## 📖 نظرة عامة

نظام فواتير احترافي متكامل لمنصة خدمات الصيانة والإصلاح المنزلية. يوفر فواتير تفصيلية قابلة للطباعة مع حساب تلقائي للضرائب ودعم كامل للغة العربية.

---

## ⚡ البدء السريع

```bash
# 1. تشغيل السيرفر
php artisan serve

# 2. فتح المتصفح
http://127.0.0.1:8000/admin/requests

# 3. اضغط على أيقونة الفاتورة 🧾
```
